This dashboard provides a comprehensive analysis of employee attendance, work-from-home (WFH) trends, and sick leave (SL) patterns across the organization. Key metrics like Attendance %, WFH %, and SL % are visually tracked over time, offering valuable insights for HR teams to optimize workforce management.

Tech Stack:

1. Power BI Desktop
2. Excel

📈 Key Techniques Learned:

1. Creating calculated columns and measures using DAX
2. Data modeling and dynamic visuals
3. KPI indicators and conditional formatting
4. Publishing and setting up auto-refresh in Power BI Services

Key Highlights:

📈 Overall Attendance Rate: 91.83%
💻 Work From Home Trends: 10.00%
🤒 Sick Leave Insights: 1.10%
📅 Detailed day-wise attendance and leave patterns
