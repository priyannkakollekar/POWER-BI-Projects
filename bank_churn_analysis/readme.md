
# Bank Churn Analysis Dashboard with POWER BI and EXCEL


🔍 **Objective:** To identify key factors contributing to customer churn, enabling effective retention strategies.

## Tech Stack:

1. SQL
2. Power BI Desktop
3. Excel
4. DAX Language
5. DAX Studio (for report optimization)

## Key Techniques Learned:

1. Creating calculated columns and measures using DAX
2. Data modeling and dynamic visuals
3. Implementing bookmarks and page navigation
4. KPI indicators and conditional formatting
5. Publishing and setting up auto-refresh in Power BI Services

## Key Data Insights:
1. **Credit Score:** Customers with higher credit scores are less likely to leave.
2. **Geography & Gender:** These demographics were analyzed to determine their influence on churn.
3. **Age & Tenure:** Older customers and those with longer tenures are more likely to stay.
4. **Balance & Salary:** Higher account balances and salaries correlate with retention.
5. **Product Ownership:** Customers with more products and credit cards tend to stay loyal.

## Data Assets Utilized:
ActiveCustomer, Bank_Churn, CreditCard, CustomerInfo, ExitCustomer, Gender, Geography

## Analysis Highlights: The analysis revealed that understanding what drives a customer to leave is crucial. Insights from this analysis will help develop targeted loyalty programs and retention campaigns.
